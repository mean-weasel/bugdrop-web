# Configuration

BugDrop is configured entirely through `data-*` attributes on the script tag.

## Core Attributes

| Attribute | Values | Default |
|-----------|--------|---------|
| `data-repo` | `owner/repo` | required |
| `data-theme` | `light`, `dark`, `auto` | `auto` |
| `data-position` | `bottom-right`, `bottom-left` | `bottom-right` |
| `data-welcome` | `once`, `always`, `false`/`never` | `once` |
| `data-color` | Hex color (e.g. `#FF6B35`) | `#14b8a6` |
| `data-button-dismissible` | `true`, `false` | `false` |
| `data-button` | `true`, `false` | `true` |
| `data-label` | Any string | `Feedback` |

See [Styling](/docs/styling) for visual customization options.
