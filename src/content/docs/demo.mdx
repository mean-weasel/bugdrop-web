# Sample App Demo

Try BugDrop on the sample app test site:

**[Open the Sample App Demo](https://bugdrop-widget-test.vercel.app/)**

The sample app runs the same embeddable widget documented here, so you can test the feedback form, screenshot capture, annotation flow, and GitHub issue submission in a realistic page without installing anything first.

The BugDrop landing page also runs the widget directly. Use `/demo` when you want the separate Sample App Demo.
