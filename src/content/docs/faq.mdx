# FAQ

## Does BugDrop work with private repositories?

Yes. The GitHub App works with both public and private repositories.

## Is any data stored on your servers?

Screenshots are uploaded as part of the GitHub issue creation process and stored on GitHub, not on BugDrop servers.

## Does BugDrop use cookies or tracking?

No. BugDrop uses no cookies, no tracking, and no analytics. URLs in bug reports are automatically redacted.

## Can I customize the widget's appearance?

Yes. BugDrop supports extensive [styling customization](/docs/styling) through `data-*` attributes.

## What browsers are supported?

BugDrop works in all modern browsers (Chrome, Firefox, Safari, Edge). It uses Shadow DOM for style isolation.
