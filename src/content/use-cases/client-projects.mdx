# Client Projects

Gathering client feedback during development often means long email threads, vague descriptions, and lost context.

## How BugDrop Helps

Add BugDrop to your staging or preview environment. When a client reviews the site, they can click the feedback button, capture and annotate a screenshot, and the feedback lands as a GitHub issue in your project repo.

## Why It Works for Client Projects

- **Visual feedback** — clients show you what's wrong instead of describing it
- **No GitHub account needed** — clients don't need to know what GitHub is
- **Organized** — every piece of feedback is a trackable issue
- **Easy to remove** — when the project ships, just remove the script tag
